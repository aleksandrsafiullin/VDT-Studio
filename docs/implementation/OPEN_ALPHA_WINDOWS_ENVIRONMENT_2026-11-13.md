## Local-account provisioning

Microsoft's documented Audit Mode shortcut restarted the guest, but after an early graceful shutdown during the Audit Mode transition, both the built-in Administrator and Windows' setup account reported disabled at sign-in. That first disk was retained and detached as `Data/windows-qa.raw`. The new 80 GiB sparse disk is `Data/windows-qa-local-v1.raw`. The active QEMU process was checked to verify that it held only the new disk.
