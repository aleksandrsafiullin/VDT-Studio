## Replay

From the repository root on the reference Mac, run `zsh output/apple-local-ai-voice-2026-11-25/f00/replay.zsh`. It uses Node 24, `git archive`, the focused Vitest suite list and `pnpm agent:eval check`. Each check uses the baseline files and pre-installed dependencies. The temporary characterization file lives inside the archived source only. Exact commands, output and the fixture manifest are under `output/apple-local-ai-voice-2026-11-25/f00/`. Documentation gates run from the working repository using `PATH="/opt/homebrew/opt/node@24/bin:$PATH" pnpm docs:verify` and `git diff --check`.

The successful replay passed 102 existing tests and five added characterizations, plus the evaluator manifest check. The first characterization run reached all four review assertions, then the legacy fixture setup failed because the direct storage call still carried an optional undefined field. The corrected replay uses the same JSON boundary as the browser request and verified the 1,800 t baseline, byte-stable fixture and unchanged reopened SQLite head. Both workbooks and the characterization source are recorded in `evidence.sha256`. The largest retained evidence files are the two workbooks, each under 16 KiB. The replay processes exited and the owned archive, dependency copies and SQLite scratch directories were removed.
