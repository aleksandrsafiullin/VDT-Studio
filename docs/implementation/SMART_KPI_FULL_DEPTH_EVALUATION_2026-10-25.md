## What changed in production

Preparation policy is `smart-kpi-preparation.v10`. The shared instruction uses universal rules: preserve project definitions/qualifiers and direct factor boundaries; cancel exact unit atoms/scales; keep population and period basis; use exhaustive disjoint categories; permit independently measured lower-level ratios; reject parent-equation reversal and disguised existing metrics; do not invent geometry or values. Fixed unit conversions themselves do not gain meaningless two-unit expansions. A named fixed reference already defined in a project can be proposed as a labelled input, with its value supplied separately.

The context builder retains up to three assumptions of 160 characters per observed node and up to 8,000 characters of actual project business/model definitions. It reserves the complete instruction/recipes/schema/escaped provider envelope within the unchanged 24 KiB limit. Ancestors are ordered by distance. Distant ancestry, optional plan rows and optional prose give way before nearby siblings, direct children and immediate parents. Omission counts remain explicit. The full project semantics, including omitted text, participate in cache identity; historical committing receipts are not migrated.

A reproduced deeper-node request previously retained the root but dropped its actual parent and both siblings. That concealed an existing metric. The revised ordering has a regression test with a deep chain and crowded context, independent of industry.

The earlier global excavation projection was removed. `mining.excavation` is used only by this explicitly requested QA fixture, which puts a source excerpt and a declared measurement-unit basis into its ordinary `businessContext`. Construction/manufacturing controls use only their own project definitions. Automatic applicable-skill retrieval/binding for Suggested is not implemented here. A blank project without that reference is not certified to reproduce this exact canonical topology.

The canonical excavation skill separately clarifies its own bucket-discharge/loading-position scope, rated-versus-filled capacity, density basis and optional measurement detail. Those domain rules are not copied into the common system instruction.
