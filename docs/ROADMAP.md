direct children and rejects exact normalized copies of contextual metrics. The
prompt prohibits inverse parent/sibling identities and asks for the target's own
lower-level components or a genuine empty result. New preview/Add also blocks
old retained unsafe proposals. General business-semantic quality, including
synonym recognition, remains a separate qualification task; historical receipt
replay and explicit manual shared references retain their contract.

with an explicit breakdown. Smart recovery persistence has a quota-only,
lossless reference encoding for repeated project/history/request payloads.

corrupt or unsupported encoded evidence is retained. Browser/storage verification
for this correction is recorded separately from live-provider qualification.

around a prominent value/unit, retaining visible estimate/source notes and all
existing edit, warning, readonly and scenario-lock controls. Saved panel sizing,

calculation contracts and native qualification are separate from this redesign.

symbols, with hover/focus editing controls and bounded labels. Its expression,
validation, caret and drag/drop contracts are unchanged.
Factor-tree cards now share the neutral theme: a compact type/name/unit header,
with the unit replacing the upper-right status icon. Base and Potential are
stacked rows with labels aligned left and numbers aligned right on the same
line, without repeated units. The integrated root Effect footer is retained.

Foreground contrast is calculated automatically for dark/white/black text;
the same foreground keeps **≈** visible on colored rows. Direct and propagated value differences use
the same treatment in either direction; unchanged/unavailable comparisons and
reference groups remain neutral. Selection/highlight borders retain priority.
Graphite selection stays synchronized with the inspector; hover/focus/touch
actions retain Manual/File and eligible Input-leaf Smart entry points. Estimate marks, unavailable
values, reference groups and relation semantics remain visible. Saved positions
and card width are preserved.

## Wave 2 — Orchestrator V2 And Agent-Owned Skill Resolution

Priority: **P1**. Depends on Waves 0, 1A and the Wave 1B repository contracts.

- Preserve the original-language request and let the model inspect bounded accessible catalog cards and candidate content.
- Treat multilingual semantic retrieval as recall-only; similarity and rank never select a skill.
- Make `skill.read` selection-neutral with an append-only exact-version receipt, and make `skill.select` the only selection mutation.
- Guard selection with run-state CAS, idempotency, catalog snapshot/hash, read-before-select, ACL and revocation checks.
- Record an explicit no-applicable-skill gap; do not select a generic skill automatically.
- Generate complete JSON Schemas and examples for every tool.
- Use one strict decision protocol for BYOK and local-runner providers.
- Extend Model Agent per-error retry budgets to legacy/external loops; add backoff, same-session Model Agent budget continuation, run leases and restart recovery.
- Apply risk-based approval to existing-project formula/root/delete changes.
- Show compact skills, sources, assumptions and unresolved gaps in the normal UI.

Exit: a multilingual golden corpus produces the same explicit canonical selection or gap across equivalent requests; stale/revoked/CAS-conflicting selections make no state change; a recipe without executable closure cannot be complete.

- skill selection recall by language/domain;
- formula and dimensional correctness;
- tool first-call validity and repair iterations;
- benchmark citation/applicability completeness;
- data mapping exactness and baseline error vs reference SQL;
